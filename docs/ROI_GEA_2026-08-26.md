## ROI and loss-avoidance calculation

### Pre-DARTRIX stabilization baseline

The stated pre-stabilization defect baseline is **3%** of daily production:

- Daily production: 10,080 bags
- Defect baseline: 3%
- Modeled daily lost bags: 302 bags/day
- Modeled daily lost meat: 502 kg meat
- Modeled daily financial loss: 10,296.72 PLN/day

The daily financial loss is consistent with the stated lost-bag quantity and cost per bag:

```text
302 bags/day × 34.05 PLN/bag = 10,283.10 PLN/day
```

The supplied ROI figure uses the stated daily loss of **10,296.72 PLN/day**. Accordingly, the annualized value is:

```text
10,296.72 PLN/day × 250 production days/year
= 2,574,180 PLN/year/machine
```

### DARTRIX stabilized result

With DARTRIX bio-stabilization, using the stated operating frequencies:

- Fundamental frequency (f0): 0.0833 Hz
- Hydracore frequency: 156 Hz
- Observed defects / leaks: 0% (0 defect)

The modeled savings are therefore:

```text
ROI / savings = 2,574,180 PLN/year/machine
```

This represents avoided loss against the stated 3% defect baseline. It is a gross loss-avoidance calculation and does not subtract any DARTRIX implementation, operating, maintenance, or validation costs because none were provided.

## Scope and assumptions

- The analysis uses the telemetry and financial inputs supplied for the 26.08.2026 production record.
- The annual figure assumes 250 production days per year, as implied by the supplied calculation: 10,296.72 PLN/day × 250 = 2,574,180 PLN/year.
- The 302 bags/day and 502 kg meat/day values are retained exactly as supplied; 3% of 10,080 bags mathematically equals 302.4 bags before rounding.
- The analysis treats the stated 0% defect result as the stabilized observed outcome for this record; it does not independently establish causality or guarantee future performance.
- “ROI / savings” is presented as annual avoided loss per machine, not net ROI percentage, because machine acquisition cost and DARTRIX costs were not supplied.
